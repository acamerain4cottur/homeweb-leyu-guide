# homeweb-leyu-guide

本仓库用于归档和发布多个独立的 HTML 页面。这些页面可作为信息展示、导航或工具页使用，不针对任何特定域名或网站。

## 项目简介

homeweb-leyu-guide 是一个静态 HTML 页面集合仓库。每个页面独立存在，彼此之间无强依赖关系。仓库主要目的是方便对多个 HTML 页面进行统一版本管理和发布。

## 目录说明

```
homeweb-leyu-guide/
├── index.html          # 仓库入口页面（如有）
├── pages/              # 存放各个独立 HTML 页面
│   ├── page1.html
│   ├── page2.html
│   └── ...
├── assets/             # 公共资源文件（CSS、JS、图片等）
│   ├── css/
│   ├── js/
│   └── images/
└── README.md           # 本文件
```

- `pages/`：所有独立 HTML 页面存放于此，每个页面为一个独立功能或内容单元。
- `assets/`：存放各页面可能引用的公共样式、脚本或图片资源。

## 页面归档说明

- 每个 HTML 页面均为独立完成，可单独打开使用。
- 页面之间不共享 cookie、localStorage 或其他客户端状态（除非显式声明）。
- 页面功能与内容由各页面自身决定，本仓库仅负责存储与分发。
- 如有页面更新，会以提交历史记录形式进行版本追踪。

## 维护说明

- 欢迎提交 Issue 或 Pull Request 来改进现有页面或添加新页面。
- 提交新页面时，请确保：
  - 页面为独立 HTML 文件，无跨文件依赖（公共资源除外）。
  - 页面内不包含指向特定商业、营销或侵权内容的链接或引用。
  - 资源引用路径使用相对路径，避免使用绝对路径。
- 本仓库不提供后端支持，所有页面均为纯前端实现。
- 不建议在页面中嵌入跟踪脚本、广告或任何违反开源社区规范的内容。

## 使用方式

1. 克隆本仓库到本地：
   ```bash
   git clone https://github.com/yourusername/homeweb-leyu-guide.git
   ```
2. 直接在浏览器中打开 `pages/` 下的任意 HTML 文件即可查看。
3. 如需部署到静态托管服务（如 GitHub Pages），请参照对应服务文档进行配置。
